### 2.8 FAQs (10 High-Value Questions)
1. **Who pays for the OpenAI or Vector Database API costs?**  
   *Answer*: The buyer pays third-party API costs (OpenAI, Anthropic, Pinecone) directly via their own account keys. I assist you in configuring cost alerts and optimization settings to keep expenses minimal.
2. **Will my sensitive company data be kept private?**  
   *Answer*: Yes. We utilize enterprise API endpoints (OpenAI API / AWS Bedrock) where data is explicitly NOT used to train public models. Strict NDA and data privacy protocols are followed.
3. **Can the chatbot handle scanned PDFs or image documents?**  
   *Answer*: Yes! We incorporate OCR (Optical Character Recognition) processing pipelines using AWS Textract or Unstructured.io for scanned media.
4. **How does the chatbot prevent hallucination or making up facts?**  
   *Answer*: We enforce strict system prompt guardrails requiring the bot to answer *only* using retrieved document chunks. If context is missing, it responds with a customizable fallback message.
5. **Do I get full ownership of the source code?**  
   *Answer*: Absolutely. 100% intellectual property ownership and raw source code (Git repository) are transferred to you upon order completion.
6. **Can this bot be integrated into my existing website or SaaS app?**  
   *Answer*: Yes, we deliver clean iframe embed codes, React component libraries, or standard REST API endpoints for seamless integration into any site.
7. **What vector databases do you support?**  
   *Answer*: We support Pinecone, Qdrant, Weaviate, Chroma, pgvector (PostgreSQL), and Redis Vector Search.
8. **What cloud environments can you deploy to?**  
   *Answer*: AWS (Lambda, ECS, Bedrock), Google Cloud Platform (GCP), Azure, Vercel, or client-owned VPS/Docker servers.
9. **What if my documents change frequently?**  
   *Answer*: We build dynamic re-indexing pipelines that automatically update vector embeddings whenever a file is added, edited, or deleted in your storage repository.
10. **What happens if I need support after delivery?**  
    *Answer*: Every package includes post-delivery support (Basic: 7 days, Standard: 14 days, Premium: 30 days). Long-term maintenance retainers are also available.
